# 롯데백화점 신규 뮤즈 캠페인 페이지

블랙&화이트, 헤리티지 무드의 인터랙션/애니메이션 중심 캠페인 랜딩 페이지.
Gucci Ancora, Burberry Trench 170 캠페인 사이트를 레퍼런스로 한 정적(빌드 불필요) HTML/CSS/JS 페이지입니다.

## 실행 방법

빌드 도구 없이 정적 파일만으로 동작합니다. 로컬에서 확인하려면:

```
cd lotte-muse-campaign
python3 -m http.server 8000
# http://localhost:8000 접속
```

`fetch(HEAD)`로 자산 존재 여부를 확인하는 로직이 있어 `file://`로 직접 열면 동작하지 않을 수 있습니다. 반드시 로컬 서버로 열어주세요.

## 페이지 구성 (3단계)

| 단계 | 노출 조건(기본) | 내용 |
|---|---|---|
| `teaser` | 10/12 이전 | 데이지 심볼 라인 드로잉 + 카피 + 10/12까지 카운트다운 |
| `phase1012` | 10/12 ~ 10/20 | 이미지/영상 1컷 + 메인 카피 + "COMING SOON · 10/21" |
| `phase1021` | 10/21 이후 | 다른 이미지/영상 1컷 + 다른 메인 카피 + "COMING SOON" |

단계는 `script.js` 상단 `SCHEDULE` 객체의 날짜를 기준으로 **자동 전환**됩니다. 실제 일정이 재확인되면 이 두 날짜만 수정하면 됩니다.

```js
const SCHEDULE = {
  phase1012: new Date("2026-10-12T00:00:00+09:00"),
  phase1021: new Date("2026-10-21T00:00:00+09:00"),
};
```

### 내부 검수/미리보기

실제 날짜가 되기 전에 각 단계를 미리 보려면 URL에 `?dev=1`을 붙이세요. 우측 하단에 단계 전환 패널이 나타나고, 선택한 단계는 `localStorage`에 저장되어 새로고침해도 유지됩니다("Auto(날짜)" 버튼으로 원래대로 복귀). 또는 `?phase=teaser` / `?phase=phase1012` / `?phase=phase1021` 쿼리로 1회성 미리보기도 가능합니다.

## 자산(이미지/영상) 교체 방법

디자인/콘텐츠 자산이 아직 없어서 현재는 모든 이미지 영역이 우아한 그레이스케일 플레이스홀더로 표시됩니다. **자산이 도착하면 아래 경로에 정해진 파일명으로 넣기만 하면 코드 수정 없이 자동으로 교체됩니다** (페이지가 로드 시 `HEAD` 요청으로 파일 존재 여부를 확인함).

```
assets/
  images/
    teaser-bg.jpg     ← 티저 단계 배경 (선택, 없어도 심볼만으로 동작)
    phase-1012.jpg    ← 10/12 버전 메인 이미지 (9/28 1차 수급분)
    phase-1021.jpg    ← 10/21 버전 메인 이미지
    story.jpg         ← 헤리티지 스토리 섹션 이미지
  video/
    teaser.mp4         ← 있으면 이미지보다 우선 노출
    phase-1012.mp4
    phase-1021.mp4
```

영상이 있으면 이미지보다 우선 사용됩니다(총 2개 영상 예정 → `phase-1012.mp4`, `phase-1021.mp4`에 배치). 세 번째 이미지(순차 수급분)는 스토리 섹션(`story.jpg`) 또는 추가 단계용으로 사용하도록 확장 가능합니다.

## 카피(문안) 교체

`index.html` 내 각 단계 섹션의 헤드라인/서브카피는 **자리표시(placeholder) 문안**입니다. 9월 내 1차 문안이 확정되면 아래 위치의 텍스트만 교체하세요.

- 티저: `<p class="headline headline--sm">` (심볼 아래)
- 10/12: `<h1 class="headline">` 내 `.line-inner` 2줄 + `.subcopy`
- 10/21: `<h1 class="headline">` 내 `.line-inner` 2줄 + `.subcopy`

심볼(데이지 라인아트)은 실제 뮤즈 심볼 그래픽이 정해지면 `index.html`의 `<svg class="symbol-svg">` 블록을 교체하거나, 별도 SVG 파일을 만들어 `<img>`로 교체하세요.

## 주요 인터랙션

- 커스텀 커서(링 + 도트, 인터랙티브 요소 위에서 확대) — 터치 기기에서는 자동 비활성화
- 인트로 프리로더(워드마크 → 와이프 전환)
- 스크롤 등장 애니메이션(`IntersectionObserver` 기반, `prefers-reduced-motion` 대응)
- 헤드라인 라인 단위 마스크 리빌
- 히어로 이미지 마우스 패럴랙스 + 은은한 줌
- 무한 마퀴 텍스트 밴드
- 필름 그레인 오버레이(SVG 노이즈, 미세하게 움직임)
- 데이지 심볼 스트로크 드로잉 애니메이션(티저 단계)
- 실시간 카운트다운(티저 → 10/12)

## 알림 신청 폼

`#notify-form`은 현재 프론트엔드 유효성 검사와 성공 메시지만 구현되어 있습니다. 실제 이메일 수집 백엔드/API가 정해지면 `script.js`의 `notifyForm.addEventListener("submit", ...)` 내부에 실제 전송 로직을 연결하세요.
