Scroll Masking스크롤 마스킹 디졸브

스크롤하는 만큼 다음 비주얼이 아래에서부터 부드러운 그라디언트 마스크로 차오르며 이전 비주얼을 덮습니다. 이미지와 큰 타이포그래피가 서로 다른 속도로 움직여 제품 소개 페이지 같은 몰입감을 줍니다.

  1. 고정 무대 KV를 sticky로 고정하고, 비주얼 1장당 스크롤 1.2화면을 배정
  2. 마스크 linear-gradient(to top) 마스크가 경계 폭 45%로 아래에서 위로 차오름
  3. 관성 스크롤 값을 바로 쓰지 않고 매 프레임 8%씩 따라가게 해 멈춘 뒤에도 부드럽게 정착
  4. 패럴랙스 이미지 6%, 큰 타이포 14% 거리를 각각 다른 속도로 이동
  5. 카피 마스크가 45% 넘게 차오른 뒤 페이드업, 덮이는 쪽은 위로 빠지며 사라짐

인터랙션 스펙

트리거스크롤 위치 (1.2화면당 1장)
마스크linear-gradient, feather 45%
보간lerp 0.08 / frame + smoothstep
정지 구간구간 앞뒤 12%는 고정
구현sticky + CSS mask-image + rAF
참고실서비스에선 첫 화면 이후 섹션에 배치 권장

관성 값이 낮을수록 스크롤을 멈춘 뒤에도 화면이 더 길고 부드럽게 따라옵니다. 비주얼은 코드로 그린 플레이스홀더입니다.
